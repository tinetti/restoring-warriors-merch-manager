The problem

01The user's friend manages a Godaddy ecommerce store selling branded merchandise (t-shirts, hats, mugs) across 3 product families.

02Godaddy's store management UI is primitive and buggy for handling SKUs, pricing, variants, and product descriptions — making even basic operations tedious and error-prone.

03The CSV export/import is the only reliable bridge, but Godaddy's CSV format is cumbersome: auto-generated SKUs are cryptic, variant relationships are implicit, and image handling is opaque.

Goals ×3
01 Handle variants and SKU rules cleanly — auto-generate readable, consistent SKUs from variant attributes instead of Godaddy's cryptic format
02 AI-assisted product descriptions — per-product rewrite button for generating or improving product copy
03 Save time and reduce errors — local web app for comfortable editing, validated CSV export for import
Done when 5 signals · all mechanically checked
  • 01
    Import CSV parses correctly and products appear correctly on Godaddy after import npx tsx src/index.ts export --input products.json --output test-export.csv && diff test-export.csv godaddy-products-export.csv (structural comparison — column order, variant relationships, SKU format)
  • 02
    Idempotent uploads — re-running export doesn't create duplicates or corrupt data npx tsx src/index.ts export --input products.json --output export-1.csv && npx tsx src/index.ts export --input products.json --output export-2.csv && diff export-1.csv export-2.csv (should produce identical files)
  • 03
    SKU auto-generation produces consistent, readable SKUs from variant attributes npx tsx src/index.ts export --input products.json --output test-export.csv && grep -c 'SKU' test-export.csv | assert > 0 && grep SKU test-export.csv | awk -F, '{print $1}' | sort -u | assert count matches expected unique SKU count
  • 04
    Images are organized into the correct directory structure for Godaddy import npx tsx src/index.ts export --input products.json --output test-export.csv && find ./godaddy-images/ -type f | assert count matches number of unique product images
  • 05
    AI rewrite produces a usable product description for review Judgment call — human verifies rewritten description is readable, appropriate, and better than the original

MVP ×5
MVP — must ship ×5
  • CSV import: read and parse Godaddy's export CSV format— Foundation for everything — without parsing the source format, nothing else works
  • Local web app: browse and edit products with variants— Core interaction model — replaces the buggy Godaddy UI
  • Variant/SKU management: auto-generate SKUs from variant attributes— Primary pain point identified in the interview
  • CSV export: write valid Godaddy-importable CSV— Delivery mechanism — the only way to push changes to Godaddy
  • Image handling: organize images into the directory structure Godaddy expects— Images are part of the product data that Godaddy's importer scans
Full — target outcome ×4
  • AI-assisted product descriptions: per-product rewrite button— Explicitly requested goal; improves description quality
  • Price management: easy bulk or per-product price editing— Variants pricing is tedious in Godaddy UI
  • Validation: pre-export checks for common Godaddy import errors— Reduces failed imports and data corruption
  • Product family management: group by brand (In Jesus Name, Restoring Warriors, Snapback)— Real-world organizing principle from the interview
Stretch — if time permits ×3
  • Bulk AI rewrite across all products— Convenience, not necessity
  • Version history / diff view between edits— Nice-to-have for audit trail
  • Direct Godaddy API integration (future when API is better)— CSV-only is intentional MVP constraint
Out of scope — said no on purpose
  • Payment / checkout functionality — This is a management tool, not a storefront
  • Order sync or inventory management — Not needed for the friend's workflow
  • Godaddy API integration — CSV is the only reliable bridge; API would be a future consideration
  • Multi-user support — Single user (the friend) for now
Future — someday, maybe
  • Codex integration — how AI assistants fit into the workflow
  • Direct Godaddy API once their API is stable
  • Multi-store support
